# 2D Platformer Game (Godot) – Learning Project

This is a simple **2D platformer game** I created using **Godot Engine** as part of my learning journey.  
I followed a Brackeys tutorial on YouTube and tried to understand the basics of 2D game development such as movement, jumping, collision, and simple level design.

The game **does not have audio yet**

---

## 🎮 What I’ve Learned So Far

- Creating scenes and nodes in Godot  
- Basic player movement using **GDScript**  
- Making the character **run and jump**  
- Using **TileMap** to build a level  
- Basic **collision** and **physics** in Godot  
- Adding simple animations using `AnimatedSprite2D` or `AnimationPlayer`
